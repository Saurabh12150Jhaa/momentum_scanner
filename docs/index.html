Features

Everything you need for systematic momentum trading in Indian equities.

🔍

Multi-Strategy Scanner

3 scan types — Momentum Universe, Breakout Candidates, Pullback-to-EMA — powered by Chartink API with yfinance fallback.

📊

Interactive Dashboard

Candlestick charts with EMA 50/150/200 overlays, RSI, volume analysis. Powered by Streamlit and Plotly.

🎯

Weinstein Stage Analysis

Automatic Stage 1-4 classification. Visual stage labels and buy/sell signal detection on every chart.

💰

Position Sizing

Risk-based sizing (2% rule), multiple stop loss methods (ATR, fixed %, DMA), R:R targets, max-position warnings.

📈

Shareholding Patterns

Full SEBI-mandated breakdown from Screener.in — Promoter, FII, DII, Government, Public with quarterly trends.

🚦

Market Regime Detection

Nifty 50 vs 200-DMA + India VIX analysis. Auto-classifies BULL / CAUTION / BEAR with allocation guidance.

📝

Fundamentals

PE, ROE, D/E, PEG, OPM, NPM, quarterly results. Filters stocks by ROE > 12%, D/E < 1.5, earnings growth > 15%.

💼

Watchlist & Portfolio

Persistent watchlist and portfolio tracker with real-time P&L, unrealized gains, and position count management.

5-Layer Filtering Funnel

From ~5000 NSE stocks down to a handful of actionable setups.

1
Universe Filter
Market cap > 500 Cr, Price > Rs.50, Avg volume > 50K
2
Momentum Filter
6-month return > 20%, RSI > 55, within 25% of 52-week high
3
Technical Filter
Weinstein Stage 2 (advancing), EMA stack 50 > 150 > 200, rising 200-DMA
4
Fundamental Filter
ROE > 12%, D/E < 1.5, revenue growth > 10%, earnings growth > 15%
5
Entry Trigger
Breakout above resistance, pullback to 50-DMA, gap-up hold, volume surge, EMA crossover

Quick Start

Requires Python 3.9+ and uv. All dependencies install automatically.

CLI Scanner
# Install uv (if you don't have it) $ curl -LsSf https://astral.sh/uv/install.sh | sh # Clone the repo $ git clone https://github.com/Saurabh12150Jhaa/momentum_scanner.git $ cd momentum_scanner # Run momentum scan $ uv run scanner.py momentum # Full scan with fundamentals + CSV export $ uv run scanner.py all -f --export
Web Dashboard
# Launch the Streamlit dashboard $ uv run launch_dashboard.py # Dashboard opens at http://localhost:8502 # Features: # - Candlestick charts + EMAs + RSI # - Weinstein stage detection # - Shareholding patterns # - Position sizing calculator # - Watchlist & Portfolio tracker
